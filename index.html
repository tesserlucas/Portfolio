04

Projeto Gerador Interno de Usuários

Aplicação desktop desenvolvida em Python para automatizar a criação de usuários internos utilizados no processo de implantação de clientes. O sistema gera automaticamente contas para gestores, caixas, garçons, atendentes (SmartPOS) e KDS, criando senhas aleatórias e seguras para cada usuário. Além da geração automática, a aplicação permite copiar rapidamente os acessos, exportar os dados para PDF e Excel, além de manter um histórico persistente dos últimos usuários gerados. O projeto foi desenvolvido para reduzir tarefas repetitivas, minimizar erros manuais e agilizar o processo operacional da equipe.
